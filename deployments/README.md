# Network profiles

Astatine Miner includes network profiles for Injective EVM. The Testnet profile identifies the chain, public RPC endpoints, AST token, and nine mining-node contracts with runtime-code hashes. These addresses, chain IDs, and hashes are public deployment references, not credentials.

The Mainnet profile is read-only and contains no Astatine mining-node or token addresses. Transaction signing is available only on Testnet.
